# AI Swim Assistant: Asisten Renang Cerdas untuk Atlet Paralimpik Tunanetra 🏊‍♂️
AI Swim Assistant adalah sebuah solusi inovatif berbasis teknologi yang dirancang untuk mengatasi tantangan unik yang dihadapi oleh perenang paralimpik tunanetra. Ide proyek ini diusulkan untuk 
Samsung Solve for Tomorrow 2025 oleh tim Lets Go Bion dari Bina Nusantara University.
Solusi ini mengintegrasikan dua komponen utama berbasis AI dalam perangkat yang bisa dipakai (wearable) untuk meningkatkan keselamatan, kemandirian, dan performa atlet

Demo Streamlit : https://ai-swimm-assitance.streamlit.app/
